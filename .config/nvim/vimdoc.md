# 🔍 Vim: Поиск, навигация и редактирование

---

• Ctrl + e — прокрутить экран на одну строку вниз (текст едет вверх, курсор остается на месте, пока не окажется за пределами экрана).
• Ctrl + y — прокрутить экран на одну строку вверх (текст едет вниз, курсор остается на месте)

• zz — переместить строку с курсором в центр экрана.
• zt — переместить строку с курсором в верхнюю часть экрана.
• zb — переместить строку с курсором в нижнюю часть экрана

• ci" (или ci(, ci{) — удалить всё внутри кавычек (или скобок) и сразу перейти в режим вставки. Буква c означает change, i — inside. Можно менять на ca", чтобы удалить вместе с кавычками (around).
• diw — удалить слово, на котором стоит курсор, не удаляя пробел после него (delete inside word).
• dd — вырезать (удалить) текущую строку целиком.
• o / O — вставить новую строку ниже (строчная o) или выше (прописная O) текущей и сразу перейти в режим вставки.

Быстрое перемещение (навигация)

• * (звёздочка) — подсветить слово под курсором и найти его следующее упоминание в файле. Нажатие # ищет то же самое слово, но вверх по тексту.
• gg / G — мгновенно прыгнуть в самое начало файла (gg) или в самый конец файла (G).
• f + символ — прыгнуть вперед по строке до первого указанного символа (например, f, перенесет курсор к ближайшей запятой).

Работа с регистром и отменой

• ~ (тильда) — поменять регистр буквы под курсором (из заглавной в строчную и наоборот).
• u / Ctrl + r — отменить последнее действие (u — undo) или вернуть отмененное действие обратно (Ctrl + r — redo).

Поиск и замена

• :%s/что_искать/на_что_менять/g — заменить текст по всему файлу. Если в конце добавить gc вместо g, Vim будет запрашивать подтверждение для каждой замены.

## 1. Сохранение и выход
* **`Ctrl + s`** (или `Ctrl + ы`) — **сохранить все открытые файлы** (работает в любом режиме)
* **`:w`** + `Enter` (или `:ц`) — сохранить текущий файл
* **`:wa`** + `Enter` (или `:ша`) — сохранить ВСЕ открытые файлы
* **`:q`** + `Enter` (или `:й`) — закрыть окно/файл
* **`:q!`** + `Enter` (или `:й!`) — закрыть без сохранения изменений
* **`:wq`** + `Enter` (или `:цй`) — сохранить и выйти

---

## 2. Поиск текста через слэш `/`
* **`/слово`** + `Enter` — найти слово или фразу вперед по файлу.
* **`n`** (*next*) — перейти к **следующему** найденному совпадению (вниз).
* **`Shift + n`** (**`N`**) — перейти к **предыдущему** совпадению (вверх).
* **`Esc`** — мгновенно убрать цветную подсветку найденных слов после поиска.

### Умный регистр (Smart Case):
* Если писать запрос маленькими буквами (например, `/config`) — найдутся и `config`, и `Config`, и `CONFIG`.
* Если в запросе есть хотя бы одна заглавная буква (например, `/Config`) — поиск будет строго с учетом регистра.

---

## 3. Быстрый поиск слова под курсором (`*` и `#`)
* **`*`** (**`Shift + 8`**) — найти слово, на котором сейчас стоит курсор, вперед по файлу.
* **`#`** (**`Shift + 3`**) — найти слово, на котором сейчас стоит курсор, назад (вверх).
* Дальше для перемещения по совпадениям нажимайте **`n`** или **`Shift + n`**.

---

## 4. Поиск назад через `?`
* **`?слово`** + `Enter` — поиск текста снизу вверх (в обратную сторону).

---

## 5. Быстрая замена текста (Find & Replace)
* **`:%s/старое/новое/g`** — заменить слово `старое` на `новое` во **всём файле**.
* **`:%s/старое/новое/gc`** — заменить с подтверждением для каждого случая (`y` — заменить, `n` — пропустить).
* **`:s/старое/новое/g`** — заменить только в **текущей строке**.

---

## 6. Перемещение по найденным местам
* **`Ctrl + o`** — прыжок **НАЗАД** (вернуться туда, где вы стояли до перехода).
* **`Ctrl + i`** — прыжок **ВПЕРЁД**.

---

## 7. Перемещение строк и отступы
* **`Alt + ↑`** / **`Alt + ↓`** (или `Alt + k` / `Alt + j`) — плавно переместить строку или выделенный блок строк вверх/вниз
* В **Visual mode**:
  * **`Tab`** — сдвинуть блок вправо (отступ 4 пробела)
  * **`Shift + Tab`** — сдвинуть блок влево

---

## 8. Комментирование кода
* **`Ctrl + /`** — закомментировать / раскомментировать строку (или выделенные строки).
* **`gcc`** (или **`псс`** на русской раскладке) — закомментировать / раскомментировать текущую строку.
* **`gc`** (или **`пс`** на русской раскладке) в Visual mode (`Shift + v`) — закомментировать весь выделенный блок строк.
* **`gc2j`** — закомментировать текущую строку и 2 строки вниз.

---

## 9. Прыжки Flash (замена поиску по экрану)
* Нажми **`s`** (или **`ы`**) $\rightarrow$ введи 2 первые буквы слова в любой части экрана $\rightarrow$ нажми появившуюся букву-метку $\rightarrow$ курсор мгновенно там.

---

## 10. Замена и удаление скобок/кавычек (Surround)
* `cs"'` — поменять двойные кавычки на одинарные
* `ds"` — удалить кавычки вокруг слова
* `ysiw)` — обернуть текущее слово в круглые скобки
* В Visual mode: выдели текст $\rightarrow$ нажми **`S`** $\rightarrow$ нажми нужную скобку/кавычку
