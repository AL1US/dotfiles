# 📖 Шпаргалка по вашей конфигурации Neovim

---

* Команда **`:dock`** (или **`:док`** / случайно набранное **`:вщсл`**) — открыть эту шпаргалку по конфигу
* Команда **`:vimdock`** (или **`:вимдок`** / случайно набранное **`:мшьвщсл`**) — открыть документацию по чистому Vim (поиск, замена и т.д.)


## 🧭 Навигация и перемещения
* `Ctrl + o` (или **боковая кнопка мыши Назад**) — шаг **НАЗАД** (вернуться туда, где был до перехода)
* `Ctrl + i` (или **боковая кнопка мыши Вперёд**) — шаг **ВПЕРЁД**
* `jj` или `оо` — быстрый выход из режима вставки в нормальный (Insert -> Normal)

---

## 🪟 Окна и Сплиты (через ПРОБЕЛ)
* **Разделение окна (сплиты)**:
  * `Пробел + [` — открыть новое окно **СЛЕВА**
  * `Пробел + ]` — открыть новое окно **СПРАВА**
* **Закрытие окон**:
  * `Пробел + q` — закрыть текущее окно
  * `:only` — закрыть все остальные окна, оставить только текущее
* **Перемещение между окнами**:
  * `Пробел + h` (или `Пробел + ←`) — перейти в окно **СЛЕВА**
  * `Пробел + l` (или `Пробел + →`) — перейти в окно **СПРАВА**
  * `Пробел + j` (или `Пробел + ↓`) — перейти в окно **СНИЗУ**
  * `Пробел + k` (или `Пробел + ↑`) — перейти в окно **СВЕРХУ**

---

## 📁 Дерево файлов (NERDTree — через ПРОБЕЛ)
* `Пробел + d` — открыть / закрыть дерево файлов (Toggle)
* `Пробел + n` — прыгнуть курсором в дерево (Focus)
* `Пробел + n + f` — найти текущий открытый файл в дереве
* **Навигация внутри дерева в стиле Yazi**:
  * **`l`** — **ОТКРЫТЬ** (развернуть папку или открыть файл в коде)
  * **`h`** — **НАЗАД** (свернуть открытую папку, либо выйти в родительскую папку, а в корне — подняться выше на уровень `..`)
* `s` — открыть выбранный файл **сбоку в сплите**
* `m` — **МЕНЮ УПРАВЛЕНИЯ ФАЙЛАМИ** (когда курсор в дереве):
  * `a` — создать файл (или папку, если написать со слэшем `folder/`)
  * `d` — удалить файл / папку
  * `m` — переименовать или переместить
  * `c` — скопировать
* **`0`** или **`~`** — мгновенно вернуться в изначальный корень проекта (дефолтное состояние)
* `C` (Shift+c) — сделать выбранную папку новым корнем проекта
* `I` (Shift+i) — скрыть / показать скрытые файлы (по умолчанию **всегда включены**)
* **Статус Git у каждого файла в дереве**:
  * `✔︎` — файл в Git, чистый, без несохранённых изменений.
  * `✭` — новый файл (ещё НЕ в Git) — вы сразу видите, что файл пока не отслеживается!
  * `✹` — изменённый файл (был в Git, но отредактирован).
  * `✚` — добавлен в индекс (git add), готов к коммиту.
  * `☒` — находится в .gitignore (игнорируется).
* `q` — закрыть дерево файлов

## 📑 Вкладки открытых файлов (Tabline вверху — через SHIFT)
* `Shift + l` (большая `L`) — следующая вкладка вправо
* `Shift + h` (большая `H`) — предыдущая вкладка влево
* `Пробел + w` — закрыть текущую вкладку (`:bdelete`)
* **`Пробел + s`** — **сохранить текущий файл** (`:w`)
* **`Пробел + S`** (или **`Пробел + s + a`**) — **сохранить ВСЕ открытые файлы проекта** (`:wa`)
* `Пробел + f + b` — список всех открытых файлов (Telescope)

---

## 🔍 Поиск (Telescope)
* `Ctrl + p` (или `Пробел + f + f`) — поиск файлов в текущем проекте
  * *В окне поиска:* `Ctrl + v` — открыть найденный файл сбоку
* `Пробел + f + g` — полнотекстовый поиск по содержимому всех файлов (ripgrep)
* `Пробел + f + a` — поиск файлов по всей домашней директории (`~`)
* `Пробел + g + s` — статус Git: список всех изменённых и новых файлов с предпросмотром
* `/слово` — поиск текста в открытом файле (`Esc` — сбросить подсветку)

## 🦆 Менеджер файлов Yazi
* `Пробел + y` — открыть всплывающий Yazi в текущей папке
* `h` (или `Backspace`) — на уровень вверх
* `l` (или `Enter`) — войти в папку / открыть файл в Neovim
* `a` — создать файл или папку
* `d` — удалить
* `r` — переименовать
* `q` — закрыть Yazi

## 💻 Всплывающий терминал (ToggleTerm)
* **`Пробел + 1` .. `Пробел + 9`** — открыть / скрыть терминалы с 1 по 9
  * Повторное нажатие на ту же цифру скрывает терминал (процесс внутри НЕ завершается)
  * Терминалы создаются только тогда, когда вы их вызываете (неактивные не тратят ресурсы)
  * В заголовке терминала сверху пишется его номер: `Terminal #1`, `Terminal #2`
  * Прямо из терминала: **`Alt + 1` .. `Alt + 9`** — быстро переключаться между ними
  * Свернуть терминал: **`Ctrl + \`**

## ⚙️ LSP и Автодополнение (Python / Pyright)
* `import os; os.` -> `Tab` / `Enter` — всплывающее автодополнение
* **`Ctrl + Клик мыши`** — перейти к функции / классу / импорту (как в PyCharm / VS Code)
* **Подсказки аргументов функций (Signature Help)** — при вводе `(` всплывает плавающее окно с параметрами функции, а текущий параметр подсвечивается жирным
* `gd` — перейти к объявлению функции / класса
* `Shift + k` (`K`) — документация и типы аргументов под курсором
* `Пробел + r + n` — переименовать переменную/функцию везде
* `[d` и `]d` — переход к предыдущей / следующей ошибке

## 💬 Комментирование кода
* **`Ctrl + /`** — закомментировать / раскомментировать строку (или выделенный блок)
* **`gcc`** (или **`псс`** на русском) — закомментировать / раскомментировать текущую строку
* **`gc`** (или **`пс`** на русском) в Visual mode — закомментировать / раскомментировать выделенные строки

## 🚀 Мгновенные прыжки по экрану (Flash)
* **`s`** (или **`ы`** на русском) + две буквы слова — на экране появятся цветные буквы-метки. Нажми нужную букву, и курсор мгновенно перелетит туда.
* **`S`** (или **`Ы`** на русском) — прыжок по синтаксическим деревьям (Treesitter).
* **`Esc`** — отменить прыжок.

## 🎯 Магия со скобками и кавычками (Surround)
* **`cs`** (*change surround*) — **заменить** окружающие символы:
  * `cs"'` — заменить `"слово"` на `'слово'`
  * `cs'(` — заменить `'слово'` на `( слово )`
  * `cs't` — обернуть в HTML-тег: `<div>слово</div>`
* **`ds`** (*delete surround*) — **удалить** окружающие символы:
  * `ds"` — убрать кавычки вокруг: `"слово"` $\rightarrow$ `слово`
  * `ds(` — убрать круглые скобки вокруг: `(слово)` $\rightarrow$ `слово`
* **`ysiw`** (*you surround inner word*) — **обернуть слово**:
  * `ysiw"` — обернуть текущее слово в кавычки: `"слово"`
  * `ysiw(` — обернуть слово в скобки: `( слово )`
* В **Visual mode**:
  * Выдели текст через `v` $\rightarrow$ нажми большую **`S`** $\rightarrow$ введи символ (например, `"`, `'`, `(`, `[`, `{`).

## ⌨️ Отступы и перемещение кода
* **`Tab`** — сдвинуть выделенные строки **вправо** (добавить отступ в 4 пробела)
* **`Shift + Tab`** — сдвинуть выделенные строки **влево** (убрать отступ)
* *Табуляция строго фиксирована:* 1 шаг = ровно 4 пробела (кратное округление `shiftround`).
* **`Alt + ↑`** (или **`Alt + k`**) — переместить выделенные строки **ВВЕРХ**
* **`Alt + ↓`** (или **`Alt + j`**) — переместить выделенные строки **ВНИЗ**
  *(Работает и в Normal mode для текущей строки, и в Visual mode для выделенного блока! Отступы сохраняются и подравниваются).*

## ⚠️ Ошибки и диагностики (LSP)
* **Наведение мыши** на подчёркнутую ошибку — сразу покажет плавающее окно с текстом ошибки
* **Остановка курсора** на строке с ошибкой — автоматически откроет всплывающее окно
* **`gl`** или **`Пробел + e`** — открыть текст ошибки под курсором вручную
* **`[d`** / **`]d`** — прыжок к предыдущей / следующей ошибке в файле

---

## 🌿 Git в реальном времени (Gitsigns)
* Полоски слева у номеров строк:
  * ┃ **Зелёная** — добавленные строки
  * ┃ **Синяя** — изменённые строки
  * _ **Красная** — удалённые строки
* **`]c`** — прыжок к **следующему** изменению Git
* **`[c`** — прыжок к **предыдущему** изменению Git
* **`Пробел + h + p`** — предпросмотр изменения (диффа) в плавающем окне
* **`Пробел + h + r`** — откат изменения в текущей строке (Reset Hunk)
* **`Пробел + h + b`** — Git Blame (кто и когда изменил эту строку)
* **`Пробел + g + c`** — **сохранить (закоммитить) всё в Git с корня проекта**:
  * Сохраняет все открытые файлы (`:wa`)
  * Добавляет все файлы проекта в индекс (`git add -A` от корня проекта)
  * Запрашивает сообщение коммита (Enter — авто-сообщение)
* **`Пробел + g + p`** — отправить изменения на GitHub (`git push` из корня проекта)

### 🏷️ Обозначения статусов файлов в дереве (NERDTree):
* `✔︎` — файл в Git, чистый, без несохранённых изменений.
* `✭` — новый файл (ещё НЕ в Git) — вы сразу видите, что файл пока не отслеживается!
* `✹` — изменённый файл (был в Git, но отредактирован).
* `✚` — добавлен в индекс (git add), готов к коммиту.
* `☒` — находится в .gitignore (игнорируется).
